# Design

The decisions behind Domicile, and what each one rejected.

## Gateway core independent of the tunnel

**Decision.** The core waits for any `utun` that owns the default route; the tunnel process is a separate concern. Phase C adds optional sing-box supervision.

**Why.** The author already runs several VLESS clients — sing-box and Xray-based Network Extension apps. Coupling the gateway to one would be arbitrary; ownership of the default route is the only contract that matters.

**Rejected.** Baking sing-box into the core.

## No packet filter

**Decision.** No `pf` rules at all.

**Why.** Verified in the sing-box source (`protocol/tun/inbound.go`, `JudgeFlow`): the tun inbound never checks source addresses, and replies are written back with the LAN client as destination, so kernel forwarding (enabled by Internet Sharing) plus the connected `bridge100` route suffice.

**Rejected.** The original scripts' `pfctl -f -`, which replaced the main ruleset and flushed Apple's `com.apple.internet-sharing` anchor.

## In-process system APIs, no spawned tools

**Decision.** Everything goes through SystemConfiguration (SCPreferences, SCDynamicStore, SCNetworkService), CoreWLAN, the PF_ROUTE routing socket, Security, URLSession, and os.log.

**Why.** No parsing of tool output, the behavior is auditable in one place, and the APIs are event-capable. The one tool without a public API — `pfctl` — was eliminated by the no-packet-filter decision.

**Rejected.** `Process`-wrapping `networksetup`, `ifconfig`, `route`, `security`, and `curl`.

## Event-driven supervisor

**Decision.** A single `AsyncStream<Event>` is fed by SCDynamicStore notifications, the CoreWLAN delegate, DispatchSourceSignal, and timers. Deadlines and heartbeats are events too; each step `waitUntil`s a condition.

**Why.** Fixed `sleep`s are racy — the scripts disassociated Wi-Fi twice blindly because they could not observe the interface re-associating.

**Rejected.** Racing `next()` against a timer task: cancelling an `AsyncStream` consumer terminates the stream.

## DNS at the resolver layer

**Decision.** While up, the uplink service's DNS is set to a public resolver (default `1.1.1.1`) through SCNetworkProtocol and restored from the persisted run record on teardown.

**Why.** Sharing clients use the Mac's resolver, the Mac's resolver follows the default route into the tunnel, and the iPhone's carrier DNS would otherwise leak and geo-mismatch.

**Rejected.** A `pf` `rdr` of client port 53. Noted alternative for phase C: a sing-box `hijack-dns` route rule.

## Internet Sharing through its own preferences

**Decision.** `com.apple.nat.plist` is driven via SCPreferences. A reference snapshot is taken while the Sharing pane has sharing on; `up` restores it with `Enabled = 1`, `down` sets `Enabled = 0`.

**Why.** It is the mechanism the Sharing pane itself uses. Disabling drops keys, hence the snapshot.

**Rejected.** Synthesizing the NAT dictionary — the schema is undocumented.

## The AP password is owned by the Sharing pane

**Decision.** The keychain item is never written; `up` only checks its presence with `SecItemCopyMatching`.

**Why.** Trusted-app ACLs exist only in the deprecated legacy keychain API (`SecAccessCreate` — "SecKeychain is deprecated", and `kSecAttrAccess` excludes data-protection items). The pane already stores the password with the ACL `airportd` needs.

**Rejected.** The scripts' per-run `security add-generic-password`, and a dedicated `set-password` command.

## Recoverable teardown

**Decision.** A LIFO undo stack covers the live run, and a persisted `run.json` lets `down` reconstruct teardown after a crash. PID identity is verified with `proc_pidpath` before any signal is sent.

**Why.** A stale pid left in the state file after a reboot must never be signalled — it could belong to an unrelated process.

**Rejected.** `pkill -x`.

## Root CLI now, menu bar app later

**Decision.** The core is UI-agnostic. A future menu bar app runs the gateway inside a privileged launchd helper (SMAppService) over XPC.

**Why.** A GUI cannot run as root.

**Consequence.** Console output must move behind a reporter seam — see `TD-2` in <doc:TechDebt>.

## Localization-ready

**Decision.** English source strings go through `String(localized:bundle:)`, with a single catalog regenerated by `Scripts/update-strings.sh` from compiler-emitted `.stringsdata`.

**Rejected.** Hand-edited catalogs. `xcstringstool extract` alone — its lightweight parser emits `%arg` placeholders, not the runtime's `%@` keys.
